❓ Panduan Cepat Teknisi

Lampu U.are.U 4500 tidak menyala?

Lampu scanner secara normal memang mati saat standby untuk menghemat daya. Lampu merah/biru akan otomatis menyala ketika web meminta verifikasi.

Status "Scanner Terlepas"?

Cabut kabel USB scanner, tunggu 3 detik, lalu colokkan kembali ke port USB yang berbeda. Halaman ini akan mendeteksi ulang otomatis.

Port 8080 bentrok dengan aplikasi lain?

Pastikan tidak ada web server lain yang menggunakan port 8080. Port dapat disesuaikan pada file konfigurasi jika diperlukan.
